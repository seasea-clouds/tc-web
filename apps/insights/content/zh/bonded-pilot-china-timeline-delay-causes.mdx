保税试点从启动到上线要多久，落在约十四到三十四周的一个条件区间里，而不是钉死在某一个日期上。区间落在哪一端，取决于关键路径上的两件事，实体注册与平台及资金账户，也取决于六类滑期里您可控的那几件。源材料第七章 Clear Numbers 给出的读法是：时间按区间看，成本按结构看，回报留给您的模型去算。本篇把第七章的四页内容一次讲透：关键路径与九阶段排期、我方可控与您方输入的区间表、六类滑期因子与代价、六里程碑与所需输入，不需要您先读过其他章节。

![SinoTrade Compliance 品牌资料第七章隔页：章号 07 章名 Clear Numbers，章旨一句话与三个引导问题](/images/insights/bonded-pilot-china-timeline-delay-causes/chapter-07-clear-numbers-divider.webp)

这张图来自品牌方资料的第七章隔页：章号 07，章名 Clear Numbers，直译是清楚的数字。隔页给出一句话章旨：时间按区间呈现，成本按结构呈现，回报由您自己的模型去算。隔页还列出本章回答的三个问题：从启动到上线关键路径卡在哪里、需要多少人多少钱哪些材料、单均毛利由哪些参数推动。本篇覆盖其中的时间与排期部分，四页内容逐页讲透。

## 从启动到上线的关键路径与九阶段

排期图上有一个核心记号：D-Day，即上线日，是第一个保税放行日，也是第一阶段最硬的检查点。时间轴从今天一直排到第三十四周。图例分三色：深蓝条是关键路径，中蓝条是非关键阶段，浅蓝条是 D-Day 之后的常态化运营。九行从上往下依次是：S0 诊断检查约两周，图上取中值演示；S1 实体注册四到十二周，关键路径；S2 平台与资金账户四到八周，与 S1 并行；S3 产品准入与备案二到六周，与 S2 并行；S4 首程物流与入区二到四周；S5 三单清关一到两周；然后是 D-Day 首次放行这个关键检查点；S6 结算按月节奏走；S7 及以后的持续运营常态开展。

![第七章排期图：Kick-off to Launch 关键路径与九阶段甘特图，S0 到 S7+ 九行时间条与 D-Day 关键检查点竖线](/images/insights/bonded-pilot-china-timeline-delay-causes/kick-off-to-launch-critical-path-nine-phases.webp)

这页的标题是 Kick-off to Launch: Critical Path and Nine Phases，从启动到上线的关键路径与九阶段。九个阶段不是九个接力棒，S1 与 S2 并行、S3 又与 S2 并行，真正串成一条线的只有关键路径上的那几段。本篇连同后面三页的排期区间、滑期因子与里程碑一起讲透，不需要您先读过本章其他模块。

关键路径为什么穿过 S1 与 S2，图下方的卡片给了答案：实体与资金账户决定您能不能开店、能不能报关、能不能结算。这两件事没有落地，下游全部排队。两件事同时启动，整条路径才锚得住。

D-Day 前后是两本账。D-Day 之前是一次性建设：实体、备案、入区、首票，预算与人员一次投入；D-Day 之后是常态化运营：结算、客服、复购、台账，按月度节拍走。两段预算分开做，不要混在一张表里。

## 排期区间：我方可控与您方输入

到上线约十四到三十四周，这是一个条件性区间。并行排期省的是真金白银的时间：S1 与 S2 并行省四到六周，S3 与 S2 并行再省二到四周。图上六条参考时长按阶段给出，两端都是真实形态，不取中值。

## 最快十四周需要什么，一个完整演算

源页把最快十四周拆成四个条件。第一，实体走平台代理路由，这是我方服务项之一，S1 压在四周内；第二，CoA 与检测报告齐套，S3 不触发复测；第三，S2 的店铺与资金账户立即并行启动；第四，口岸偏好与货量早定，文档分批到会把排期推向长端。这四条全部在您手里，我方可以按您的条件现场演示建模。

用一组演示条件把十四周走一遍。S0 两周起步；S1 走代理路由，四周落地；S2 按八周上限在并行中走完，不额外占关键路径；S3 六周与 S2 并行吸收；S4 二到四周按两周读，前提是货量早定、首程不错窗；S5 一到两周按一周读。关键路径合计两周加四周加四周加两周，约十二到十四周，落在区间下端。反过来，实体走 WFOE 注册，S1 顶到十二周上限；文档分批到，阶段串行等待；口岸偏好晚定，要备两套预案；货量晚到，首程物流错过窗口。几项叠加，排期就滑向三十四周的长端。两端都摆出来，预期才立得住。

这里的口径要说清：区间是条件性的；三十四周上限对应 WFOE 注册加文档分批的组合；除 S0 演示取中值外，图上时长都是区间，不取中值。

## 六类滑期与它们的代价

六类滑期决定您落在区间的哪一端，条长表示相对影响，条件性口径。归属标注沿用责任三分：深蓝是我方，中蓝是您提供，墨色是与我方并行。

| 归属 | 因子 | 代价 |
| --- | --- | --- |
| 用户提供 | CoA 与检测就绪 | 复测：S3 滑二到六周 |
| 用户提供 | 文档周转 | 清单晚到：S0 起点滑约两周 |
| 用户提供 | SKU 与归类负载 | 品项越多，备案越长 |
| 我方 | 依据核对 | 返工：吸收在阶段内 |
| 并行 | 首程模式 | 模式选择影响 S4 |
| 用户提供 | 实体路径（四到十二周） | 晚定：路径一一对应顺延 |

| 延误情形 | 顺延代价 | 影响 |
| --- | --- | --- |
| SKU 清单晚两周 | 滑约两周 | S0 起点顺延 |
| CoA 缺失复测 | 滑二到六周 | S3 顺延 |
| 实体路径决策晚 | 一一对应顺延 | 关键路径 |
| 口岸处理 | 标准处理时长 | 封顶 S5 排期 |
| 货量晚 | 无固定周数 | 影响 S4 |

前三个因子在您手里：CoA 就绪、文档周转、SKU 与归类负载，这三件决定您落在区间的哪一端。我方执行的是复测规划、文档清单、清单比对与补缺；原件与授权由您提供。

## 六里程碑与您的输入

M1 到 M6 是双方共同确认的交付节点，挂付款节拍。节点锚在阶段上；S3 产品准入与备案与 S2 并行，不设独立节点。六个节点依次是：

- M1，S0 完成：准入会议与分层签核，输入是 SKU 清单与 CoA。
- M2，S1 完成：实体与海关注册完成，输入是实体路径决定。
- M3，S2 完成：店铺与账户开立、测试单跑通，输入是宣称策略。
- M4，S4 完成：入区与台账备案，输入是备货量。
- M5，S5 完成：D-Day 首次放行，输入是口岸偏好。
- M6，S6 完成：首次结算与对账完成，付款按交付物。

| 输入 | 用于 | 缺失后果 |
| --- | --- | --- |
| SKU 清单含规格 | 归类备案 | S0 起点顺延 |
| 同批 CoA | 准入会议 | S3 顺延 |
| 检测报告 | 补缺背书 | 无固定周数 |
| 备货计划 | 首程排期 | S4 排期顺延 |
| 实体路径决定 | S1 启动 | 关键路径顺延 |
| 口岸偏好 | 定目标口岸 | 无固定周数 |
| 宣称策略 | 内容审批 | 无固定周数 |

输入的最晚时点要记住三条：SKU 清单与 CoA 在 S0 启动前，备货量在 S4 排期前，实体路径在 S1 启动前。六个节点是月度复盘的共同基线：每个节点对应一个可逐项验收的交付物；共同确认后节点进入付款节拍；节点状态随月度台账更新，与排期曲线同源。

最后把口径说清：十四到三十四周是条件性参考区间，不是承诺；除 S0 演示取中值外，图上时长都是区间，不取中值；里程碑是双方联合确认的节点，每笔付款对应一个交付物；WFOE 注册与文档分批是把区间推向长端的主因。您要排自己的保税时间表，可以照这个顺序走：S0 启动前备齐 SKU 清单与同批 CoA，第一周定实体路径，S1 落地当天让 S2 并行跑起来，之后按六里程碑做月度复盘。我们在中国市场的组合包里备好了这套排期表与里程碑对应的执行材料，把产品清单与目标上线时间带来，[联系我们](/zh/packages/)。

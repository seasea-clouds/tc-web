## 輸入食品の新しいルールブック

2026年6月1日、中国税関総署は政令248号を**政令280号**に置き換えました。これは中国市場に販売したい海外食品製造企業の登録に関する新しい法的根拠です。すでに中国へ食品を輸出している場合、登録番号は引き続き有効ですが、その周辺のルールは変わりました。初出荷を準備している場合、ネット上にある古いガイドの多くはすでに時代遅れです。

輸出企業にとって最も重要な変更は3つあります。第一に、本国の当局による推薦が必要な製品リストが17カテゴリーに再編されました。第二に、そのリスト外の製品は政府の推薦を必要としない自己申請のルートを利用します。第三に、いくつかの一次農産物が食品登録制度から完全に移出され、別の農産物登録の枠組みに移りました。

## 誰が登録する必要がありますか

登録の対象は、中国向け食品を取り扱う海外の**製造・加工・貯蔵施設**です。これは簡単に聞こえますが、詳細の部分で多くの企業がつまずきます。

- **製造企業**：中国向け食品を生産するすべての施設は有効な登録を保持する必要があります。
- **加工企業**：原料を完成食品に変える施設も同様に登録対象です。
- **貯蔵企業**：登録可能な貯蔵施設に該当するのは、陸生動物由来食品と水産物を貯蔵する冷蔵倉庫だけです。一般の倉庫は対象外です。
- **貿易会社**：生産施設や加工施設を持たない純粋な貿易会社は、自社名義で登録することはできません。登録は実際に食品を製造または取り扱う施設に帰属します。

この最後の点は何よりも混乱を招きます。仲介業者から「貿易会社でもそのまま登録できる」と言われる輸出企業に私たちはしばしば出会います。政令280号の枠組みではそのような道は存在しません。登録主体は工場、加工ライン、または要件を満たす冷蔵倉庫でなければなりません。

## 製品はどのように分類されますか

### 17の公式推薦カテゴリー

この17カテゴリーに該当する製品は、輸出国の主管当局を通じて登録し、当局が施設をGACCに推薦する必要があります。

| カテゴリー | カテゴリー |
|------------|------------|
| 肉および肉製品 | 乾燥野菜 |
| 腸衣 | 調味粉末 |
| 燕の巣および燕の巣製品 | ナッツおよび種子類 |
| 蜂製品 | ドライフルーツ |
| 卵および卵製品 | 特別な食事用食品 |
| 食用油脂 | 保健食品 |
| 中身入りペストリー | 乳製品 |
| 食用穀物 | 水産物 |
| 穀物製粉製品および麦芽 | |

このうち**肉および肉製品**と**燕の巣製品**の2カテゴリーは自動更新されません。有効期限前に必ず更新手続きを行う必要があります。

### その他すべての製品は自己申請

17の推薦カテゴリー外の食品は、GACCが運営する**CIFERシステム**（cifer.singlewindow.cn）を通じて自己申請で登録できます。輸出国の当局による推薦状は不要です。焙煎コーヒー、茶、砂糖、菓子、スナック、飲料など、幅広い日常食品がこのルートに該当します。

### 移出された製品

油料作物、雑穀、生鮮野菜、乾燥豆、調味料、未焙煎のコーヒー豆とカカオ豆の6つの一次農産物が、食品登録制度から全体的に移出されました。これらは現在、農産物の海外企業登録を管理するGACC 2025年公告第219号の枠組みに該当します。2つの制度は登録チャネルも通関申告コードも異なるため、区別を間違えると申告の段階で詰まります。

## 事例：インドネシアのコーヒー焙煎工場の登録への道

インドネシアのコーヒー企業が私たちに相談を持ちかけました。問題は具体的でした。中国の買い手が契約の条件としてGACC登録を盛り込んでいたのに、焙煎工場はどこから始めればよいのか全く分からなかったのです。実際の焙煎ラインと包装ラインを持つ本格的な生産施設だったため、登録資格は十分にありました。欠けていたのは明確な道筋でした。

### ステップ1：製品分類の判断

最初の問いは、どの制度が適用されるかでした。答えは多くの輸出企業を混乱させる区別に懸かっていました。未焙煎のコーヒー豆は公告219号の農産物ですが、**焙煎コーヒー豆と挽いたコーヒーは政令280号の食品**です。この企業はコーヒーの焙煎と包装を行っていたため、製品は食品カテゴリーに該当し、17の推薦カテゴリー外だったので、インドネシア当局の推薦状なしで自己申請ルートを利用できました。

### ステップ2：登録主体の確認

次に私たちは、登録はグループの貿易部門ではなく、焙煎施設そのものの名義で申請しなければならないことを確認しました。施設の営業許可、住所、生産能力がすべて、システムに提出する情報と一致している必要がありました。

### ステップ3：申請書類の準備

政令280号の下で、中核となる提出書類は3つです。企業登録申請情報、現地の営業許可証などの身分証明、そして施設が登録条件を満たしていることの宣言です。私たちはインドネシア語の書類を収集し、CIFERシステムが期待する形式で申請情報を作成し、必要なものにはすべて英語翻訳を手配しました。

### ステップ4：提出とフォローアップ

私たちはアカウントを登録し、CIFERを通じて申請を提出し、審査プロセスを追跡しました。申請は約**20営業日**で承認され、企業は**C**で始まる登録番号を取得しました。これはGACCが登録済みの海外食品施設に使用する形式です。

### ステップ5：その後に必要なこと

登録はゲートであって、ゴールではありません。私たちは企業とともに海外輸出者届出を進め、登録番号を税関書類でどのように申告するかを説明し、小売パッケージの中国語ラベル要件を指摘しました。最初のコンテナが出荷されたとき、すべてのコンプライアンス要素が貨物が港を離れる前に整っていました。

この企業の学びはシンプルです。難しいのは決して申請書ではありません。どの制度が適用されるか、登録を誰の名義にするか、そしてシステムに触れる前に何を準備すべきかを知ることなのです。

## 私たちがよく見る間違い

- **登録主体の誤り**：貿易会社が自社名義で申請すると却下され、不正確な情報で取得した登録は後で取り消されることもあります。
- **製品分類の誤り**：コーヒーが典型的な例です。未焙煎豆と焙煎コーヒーは異なる規制体系に属し、混同すると申請が停滞します。
- **翻訳なしでの提出**：現地語の書類には英語翻訳が必要です。翻訳の欠落や粗雑さは、申請が補正のために返されるよくある理由です。
- **登録を唯一のステップと考えること**：通関申告コード、輸出者届出、ラベルコンプライアンスは別個の要件です。登録だけでは貨物は通関しません。

## 私たちができること

私たちは食品・飲料輸出企業のGACC登録をエンドツーエンドでサポートします。製品がどの登録ルートに該当するかを評価し、登録すべき正しい主体を検証し、翻訳付きの申請書類を準備し、CIFERを通じて提出し、登録番号が発行されるまでフォローアップします。輸出者届出、通関申告サポート、ラベルコンプライアンスなどの下流の部分もカバーします。

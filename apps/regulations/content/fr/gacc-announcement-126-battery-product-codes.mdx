L'avis n° 126 ne porte ni sur l'accès au marché ni sur une interdiction. Il modifie la déclaration. À compter du 1 septembre 2026, les produits de batterie touchés par l'ajustement des droits d'accise doivent être déclarés sous les 16 codes de marchandise de l'annexe. Ne déclarer que les 8 chiffres de la position ou se tromper de code fausse du même coup les droits d'accise à l'importation.

Un lot de systèmes de batteries lithium-ion pour véhicules électriques à batterie relève de la position tarifaire 85076000. Il faut déclarer les 10 chiffres du code et non la seule position à 8 chiffres, soit 8507600029 pour les systèmes destinés aux véhicules électriques à batterie ou hybrides rechargeables, 8507600039 pour les batteries d'aéronefs et 8507600099 pour les autres batteries lithium-ion. Un code erroné modifie les droits d'accise.

L'annexe compte 8 positions tarifaires et 16 codes de marchandise. Le terme ex impose en outre que la marchandise corresponde à la description précise de la désignation. Tout ajustement ultérieur des codes suit la base de données des paramètres de dédouanement.

<!-- original -->

Conformément à l'avis n° 20 de 2026 du ministère des Finances, de l'Administration générale des douanes et de l'Administration fiscale de l'État (portant ajustement des politiques de droits d'accise applicables à certains produits de batterie), et afin d'assurer la perception des droits d'accise à l'importation, les codes de marchandise correspondant aux produits de batterie visés par cet ajustement sont publiés par le présent avis, comme indiqué en annexe.

Le présent avis entre en vigueur le 1 septembre 2026. Lors de l'importation ou de l'exportation, les produits de batterie concernés doivent être déclarés sous les codes de marchandise figurant en annexe.

Le présent avis est ainsi publié.

Annexe : Tableau des codes de marchandise correspondant aux produits de batterie

Administration générale des douanes

28 août 2026

Tableau des codes de marchandise correspondant aux produits de batterie

(1) Piles à combustible avec une puissance de sortie ≤ 750 W, position tarifaire 85013100 (ex), code de marchandise 8501310010.

(2) Piles à combustible avec 750 W < puissance de sortie ≤ 75 KW, position tarifaire 85013200 (ex), code de marchandise 8501320020.

(3) Piles à combustible avec 75 KW < puissance de sortie ≤ 375 KW, position tarifaire 85013300 (ex), code de marchandise 8501330020.

(4) Piles à combustible avec une puissance de sortie > 375 KW, position tarifaire 85013400 (ex), code de marchandise 8501340020.

(5) Systèmes de batteries lithium-ion à l'état solide pour véhicules électriques à batterie ou hybrides rechargeables, position tarifaire 85076000 (ex), code de marchandise 8507600021.

(6) Batteries lithium-ion à l'état solide pour aéronefs, position tarifaire 85076000, code de marchandise 8507600031.

(7) Autres batteries lithium-ion à l'état solide, position tarifaire 85076000, code de marchandise 8507600091.

(8) Autres systèmes de batteries lithium-ion pour véhicules électriques à batterie ou hybrides rechargeables, position tarifaire 85076000, code de marchandise 8507600029.

(9) Autres batteries lithium-ion pour aéronefs, position tarifaire 85076000, code de marchandise 8507600039.

(10) Autres batteries lithium-ion, position tarifaire 85076000, code de marchandise 8507600099.

(11) Batteries sodium-ion et autres batteries à l'état solide, position tarifaire 85078090 (ex), code de marchandise 8507809010.

(12) Autres batteries, position tarifaire 85078090, code de marchandise 8507809090.

(13) Cellules pérovskite, cellules à l'arséniure de gallium et cellules tandem d'autres matériaux, non assemblées en modules ni en panneaux, position tarifaire 85414200 (ex), code de marchandise 8541420010.

(14) Autres cellules photovoltaïques non assemblées en modules ni en panneaux, position tarifaire 85414200, code de marchandise 8541420090.

(15) Cellules pérovskite, cellules à l'arséniure de gallium et cellules tandem d'autres matériaux, assemblées en modules ou en panneaux, position tarifaire 85414300 (ex), code de marchandise 8541430010.

(16) Autres cellules photovoltaïques assemblées en modules ou en panneaux, position tarifaire 85414300, code de marchandise 8541430090.

Note : (1) Les positions tarifaires sont celles du « Tarif douanier d'importation et d'exportation de la République populaire de Chine (2026) ».

(2) Le terme ex signifie que la marchandise doit relever de la position tarifaire et correspondre à la description précise figurant dans la colonne de la désignation des marchandises.

(3) Toute modification ultérieure des codes de marchandise suit le contenu de la base de données des paramètres de dédouanement.

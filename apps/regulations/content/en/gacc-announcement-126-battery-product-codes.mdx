Announcement No. 126 changes no market access and imposes no ban; it changes how you declare. From 1 September 2026, battery products affected by the excise tax adjustment must be declared under the 16 commodity codes listed in the annex; declare only the 8-digit heading or use the wrong code and the import-stage excise tax is wrong with it.

A consignment of lithium-ion battery systems for battery electric vehicles arrives under heading 85076000. Declare the full 10 digits rather than the 8-digit heading: 8507600029 covers systems for battery electric or plug-in hybrid vehicles, 8507600039 aircraft batteries, 8507600099 other lithium-ion batteries. A wrong code changes the excise tax.

The annex has 8 tariff headings and 16 commodity codes. The term ex means the goods must match the product description as well as fall within the heading; later code changes follow the customs clearance parameter database, so this table is not a permanent basis.

<!-- original -->

In accordance with Announcement No. 20 of 2026 of the Ministry of Finance, the General Administration of Customs and the State Taxation Administration (on adjusting excise tax policies for certain battery products), and to administer the collection of import-stage excise tax, the commodity codes corresponding to the battery products covered by the policy adjustment are hereby published, as set out in the annex.

This Announcement takes effect on 1 September 2026. Battery products shall be declared under the commodity codes listed in the annex when imported or exported.

This Announcement is hereby issued.

Annex: Table of Commodity Codes for Battery Products

General Administration of Customs

28 August 2026

Table of Commodity Codes for Battery Products

(1) Fuel cells with output ≤750 W, tariff heading 85013100 (ex), commodity code 8501310010.

(2) Fuel cells with 750 W < output ≤ 75 KW, tariff heading 85013200 (ex), commodity code 8501320020.

(3) Fuel cells with 75 KW < output ≤ 375 KW, tariff heading 85013300 (ex), commodity code 8501330020.

(4) Fuel cells with output > 375 KW, tariff heading 85013400 (ex), commodity code 8501340020.

(5) Lithium-ion solid-state battery systems for battery electric or plug-in hybrid vehicles, tariff heading 85076000 (ex), commodity code 8507600021.

(6) Lithium-ion solid-state batteries for aircraft, tariff heading 85076000, commodity code 8507600031.

(7) Other lithium-ion solid-state batteries, tariff heading 85076000, commodity code 8507600091.

(8) Other lithium-ion battery systems for battery electric or plug-in hybrid vehicles, tariff heading 85076000, commodity code 8507600029.

(9) Other lithium-ion batteries for aircraft, tariff heading 85076000, commodity code 8507600039.

(10) Other lithium-ion batteries, tariff heading 85076000, commodity code 8507600099.

(11) Sodium-ion batteries and other solid-state batteries, tariff heading 85078090 (ex), commodity code 8507809010.

(12) Other batteries, tariff heading 85078090, commodity code 8507809090.

(13) Perovskite cells, gallium arsenide cells and tandem cells of other materials, not assembled in modules or made up into panels, tariff heading 85414200 (ex), commodity code 8541420010.

(14) Other photovoltaic cells not assembled in modules or made up into panels, tariff heading 85414200, commodity code 8541420090.

(15) Perovskite cells, gallium arsenide cells and tandem cells of other materials, assembled in modules or made up into panels, tariff heading 85414300 (ex), commodity code 8541430010.

(16) Other photovoltaic cells assembled in modules or made up into panels, tariff heading 85414300, commodity code 8541430090.

Note: (1) Tariff headings are those of the Customs Import and Export Tariff of the People's Republic of China (2026).

(2) ex means the goods must fall within the tariff heading and also match the specific product description in the product name column.

(3) Any later adjustment to commodity codes follows the customs clearance parameter database.

Det här exemplet visar hur en författningsinlämning är uppbyggd.

<!-- original -->

**Artikel 1**　Dessa bestämmelser gäller utländska företag som tillverkar livsmedel för export till Kina.

**Artikel 2**　Det utländska företaget ska registrera sig hos den behöriga myndigheten före exporten.

保税プロジェクトが成立するかどうかは、まず2から4週間の診断から始まる。四つの報告書が手元に届いてから、続けるかどうかを決める。続けるなら、一つのSKUを6から10週間のパイロットに通し、初回注文が通関してから初めて拡大に入る。どのステップも止められ、止めた時点で納品済みのものはブランドに帰属する。この三文が参入ルートの全体であり、残る問いは一つだけだ。誰が署名し、誰が納品し、いつ受け入れるのかという形に、どう切り分けるか。

14の作業パッケージ、S0からS13は、診断、主体、店舗、届出から、一次運送、通関、そして精算、販促、アフターセールス、データ、監査、サプライチェーンの可視化、コンテンツコンプライアンス、会員まで続く。三歩の参入は商業的なリズムであり、分割納品ではない。診断がS0を、パイロットがS1からS5を、拡大がS6からS13をカバーする。パッケージは納品単位、ステップは意思決定の関門であり、両者を混同しないこと。

## 三つのステップと十四のパッケージを一枚の図で見る

図には三つのステップがあり、覚える数字も三つだ。参入3歩、退出点3つ、S0の成果物4つ。

最初のステップは診断で、S0をカバーし、2から4週間、4つの報告書を出す。二番目は単一SKUのパイロットで、S1からS5をカバーし、6から10週間、5つのリンクを順に着地させる。三番目は拡大で、S6からS13、全SKUをカバーし、8つのモジュールを一つずつ有効にする。各ステップの右端には白抜きの退出点があり、そのステップの終わりで退出できる。すでに納品された書類はブランドに帰属する。

下半分は三枚のステップカードで、各ステップでやるべきことが一枚のカードにまとまっている。診断カードには四つの報告書と診断後の決定、パイロットカードにはチェーンの稼働、拡大前の確認と戻し条件、拡大カードには全SKUの展開と契約段階ごとの退出を書く。作業パッケージはシステムで切るのではなく、単独で受け入れられる成果物で切る。

図上の期間は条件付きのレンジで、条件は後述する。S0は固定価格、検査と出張は実費精算だ。後でS番号が出てきたら、この図に戻れば位置が分かる。

## 最初のステップは2から4週間で明確な答えを買う

診断がやることは一つだけだ。入れるかどうか、どう入るかを判定する。四つの報告書が一度に届く。内容は次のとおりだ：

- 参入評価報告書：入れるかどうかに答える。HSコード、リスト、監督条件を示す。
- コンプライアンス根拠報告書：阻害要因があるかどうかに答える。結論の一つひとつに文書番号を付ける。
- 実行推進チェックリスト：いつ入れるかに答える。順序と必要な材料を示す。
- 港の実務確認チェックリスト：港がどう運用するかに答える。同じHSコードを目標港でどう扱うか。

診断は固定価格のサービスで、費用は書面見積もりによる。検査と出張は実費精算だ。報告書が手元に来たら、続けるか止めるかを決める。支払った費用は納品済みのものに対応し、始まらなかった段階の請求はない。

診断が買うのは「ノー」であることも多い。ある固形飲料ブランドは、二つの成分のせいで分類もポジティブリストの適格も不確かだった。報告書がHSコード、リスト、港の実務を整理し、ブランドは処方を作り直してからパイロットに入った。診断費はわずかなもので、本当に節約できたのはチェーン全体の手戻りだった。

四つの報告書は四つのスライド資料ではない。参入評価報告書は具体的なHSコードを指し、コンプライアンス根拠報告書は具体的な文書番号を指し、実行推進チェックリストは具体的な材料を並べ、港の実務確認チェックリストは具体的な港を特定できなければならない。どれか一つでも原則論にとどまれば、パイロットは問題をもう一度なぞることになる。

## 第二のステップは、一票を6から10週間のパイロットで通す

パイロットは一つのSKUだけを扱い、五つのリンクは順序を変えられない：

- 現地法人設立：営業許可証と税関登録。どちらかが欠けるとシステムは口座を開かない。
- プラットフォーム店舗：店舗公開、入金口座、決済チャネル。
- 製品登録：層分け表、分類、書類。HSコードを誤ると、以降の申告はすべて更正になる。
- 保税倉庫の一次運送：貨物が保税倉庫に入り、保税台帳が開き、在庫がブランドから見える。
- 三書類通関：注文、決済、物流の記録が一致し、初回出荷の許可が出る。

チェーンが回り、確認できてから初めて、精算と分潤の話になる。

パイロットには四つの観察項目があり、拡大に入れるかを決める。初回注文が回るか、コストの偏差がどれほどか、リピート購買の兆しが出るか、コンプライアンス上の問題がないか。四つのうち一つでも届かなければ、ロールバックする。ロールバックは失敗ではない。拡大の予算を懐に残すことであり、納品済みのものは依然としてブランドに帰属する。

ビタミンC発泡錠1800箱のロットで、初回注文240箱が通関を終えて区域外へ出た。二週目のレビューで、注文あたりのフルフィルメントコストが見積もりを22パーセント上回っていた。原因は、ケース単位のピッキングを一箱ずつに崩していたことだ。チームは包装を六箱一ケースに変え、コストは合意した範囲に戻り、それから拡大に入った。その回は予算を増やさず、二週間と一回の包装変更を足しただけだった。

初回注文が回らない場合は、三つの書類が一致しているか、登録がそのSKUをカバーしているか、コストの基準に詰め替えと返品が含まれているかを確認する。そのうえでロールバックするか再実行するかを決める。問題を開いたまま拡大しないこと。

## 第三のステップは、依存関係の順に8つのモジュールを開く

拡大はS6からS13をカバーし、8つのモジュールを一つずつ有効にする。順序は依存関係の順だ：

- 資金精算：照合明細と証憑。パイロットが回ってから最初に開く。
- 販促と流通：顧客獲得と成長の設計。安定した履行があってから有料のリーチを広げる。
- カスタマーサービスとアフターセールス：サービスと返品処理。返品プロセスがないと、会員データは汚れる。
- データリスク管理：データコンプライアンスと越境移転。何を外に出せるかを先に線引きする。
- コンプライアンス監査：自己点検、記録、照会対応。平時から記録を残し、照会時に答えられるようにする。
- サプライチェーン可視化：注文、在庫、通関、物流を一つの画面に置く。
- コンテンツコンプライアンス：商品ページとライブ配信の審査。素材を公開する前に通す。
- 会員運営：階層と定期購入。リピートが安定してから会員ランクを扱う。

拡大は全SKUを一度に広げることではない。契約で定めた段階ごとに開き、各段階には受け入れ項目があり、届かなければそこで止まる。止まるコストは、問題を抱えたまま広げるコストより通常は低い。

開くペースと初期範囲は6段階のロードマップで決める。モジュールごとの成果物と進め方はサービスカタログにあり、この図にはない。

## 十四のパッケージは署名権限で切り分ける

十四の作業パッケージはシステムで切るのではなく、署名権限で切る。各パッケージは、単独で受け入れ、単独で責任を追える一つの成果物に対応する。診断報告書には署名があり、許可証には署名があり、届出受領書には署名があり、精算書にも署名がある。署名する人がそのパッケージの責任者だ。

| コード | 作業パッケージ | 成果物 |
|---|---|---|
| S0 | 診断と参入 | 四つの報告書を一括納品 |
| S1 | 現地法人設立 | 営業許可証と税関登録 |
| S2 | プラットフォーム店舗 | 店舗公開、口座、決済 |
| S3 | 製品登録 | 層分け表、分類、書類 |
| S4 | 保税倉庫の一次運送 | 保税台帳と在庫の可視化 |
| S5 | 三書類通関 | 注文、決済、物流の三書類と初回出荷の許可 |
| S6 | 資金精算 | 照合明細と証憑 |
| S7 | 販促と流通 | 顧客獲得と成長の設計 |
| S8 | カスタマーサービスとアフターセールス | サービスと返品処理 |
| S9 | データリスク管理 | データコンプライアンスと越境移転 |
| S10 | コンプライアンス監査 | 自己点検、記録、照会対応 |
| S11 | サプライチェーン可視化 | 注文、在庫、通関、物流 |
| S12 | コンテンツコンプライアンス | 商品ページとライブ配信の審査 |
| S13 | 会員運営 | 階層と定期購入 |

こう切ると、見積もりも受け入れもパッケージに落ちる。支払う対象は十四の成果物であり、あるセルが納品されなければ、そのパッケージは受け入れない。故障の特定にも座標がある。まずどのセルかを名指しし、それから誰の担当かを話す。

パッケージには順序がある。S0が決まらなければS1とS3は始められず、S3のHSコードが決まらなければS4の入庫予報は誤り、S5が一票を通さなければS6は照合を語れない。順序を誤ると、手戻りのコストは節約した時間より高い。

計画段階では二つの接続点も確保する。9610直購チャネルと第二の供給源だ。あるカテゴリが直購しか使えない場合、または保税倉庫に急な空きがない場合、注文は9610から出し、台帳は同じものに記帳し続ける。海外の発送主体を二つ認証しておき、一方の資格や物流に問題が出れば、もう一方が引き継ぐ。接続は第一期に作り、後の段階でアーキテクチャを変えない。

## 各ステップの撤退方法を、三つの条項で書面に残す

退出点は礼儀の言葉ではなく、契約条項だ。三つのことを書き下す：

- 時点：各ステップが終わり、報告書または成果物が受け入れられた後。途中で思いつきで決めるものではない。
- 納品済みのものの帰属：報告書、アカウント、データ、届出受領書、台帳はブランドに帰属する。
- 発生していない費用の扱い：書面見積もりと実際の作業に基づいて精算する。S0は固定価格、検査と出張は実費とする。

三歩の参入は商業的なリズムであり、分割納品ではない。製品とルートがすでに明確なら、単一SKUのパイロットだけを行うこともできる。製品が新しいほど、成分が複雑なほど、診断を飛ばすのは勧められない。

拡大段階の退出は、契約で定めた段階に従う。届かなければそこで止まり、引き継ぎは6項目のチェックリストに沿って行う。費用は書面見積もりに従い、条件は正式な契約に従う。

## この進め方がカバーしないもの

枠組みが扱うのは構造であり、選択ではない。四つの問いには答えない：

- 製品がどの登録ルートを取るか。ブルーハット、保税、一般貿易のどれを選ぶかは、カテゴリ、成分、予算で決まる。
- 価格とチャネル。どのプラットフォームを選び、どの価格帯に置き、販促カレンダーをどう組むか。
- 現地法人の株式と税務の構造。
- 特定カテゴリの参入判定。HSコードごとに、リストと監督条件を個別に照合する必要がある。

この進め方が扱うのは、プロジェクトをどう切り、どう受け入れ、いつ止めるかだ。参入判定、税務アドバイス、法的アドバイスを代替するものではない。

## なぜ今動くのか、待つことで手放すもの

コンプライアンスを満たして先に入るブランドは、後発が取りにくい三つの資産を押さえる。総合保税区の台帳と港の届出枠、プラットフォームの同カテゴリでの信頼の位置、成分に対する消費者の認知だ。一歩遅れると、同じ敷居は残り、列は長くなる。

待つべき場合もある。カテゴリがポジティブリストにない、買い手が個人使用の個人でない、注文金額が限度を超える。三つのどれかが成り立たなければ、まず参入を解決し、パイロットを始めない。三つとも成り立つなら、遅延のコストは通常、診断費より高い。

私たちが扱うプロジェクトで最も多い浪費は、どこで終わり、どこで受け入れるかが定義されていないことだ。契約書は厚く、セルは空のままで、何かが壊れても相談する相手がいない。

保税プロジェクトの敷居は政策にはない。政策は公開されており、文書番号は報告書に書いてある。敷居は構造にある。長いチェーンを、署名でき、受け入れられ、退出できるセルに切り分けられるかどうかだ。十四の作業パッケージが誰が納品するかを答え、三つのステップがいつ続行を決めるかを答える。両方を契約に書き込んで初めて、プロジェクトは実際に始まる。

あるSKUを診断から始めるべきか迷っているなら、まず無料のコンプライアンス評価から始められる。カテゴリ、HSコード、目標チャネル、必要な作業パッケージを一枚の表にまとめ、どのステップから始めるかを決める。[お問い合わせ](/ja/packages/)まで、製品と発売予定時期をお知らせください。

## 中国补充剂市场的复杂性

中国是全球第二大保健食品和功能性食品市场，规模超过 850 亿美元，并以每年 8–12% 的速度增长。需求来自快速老龄化的人口、中产阶级健康意识的提升，以及疫情后全民对健康管理的重视。

但对海外品牌来说，进入这个市场并不轻松。监管框架把产品拆进**三条完全不同的路径**，每条路径的要求、周期和成本都不一样。路线选错，轻则多花几个月，重则货物被扣、罚款、市场准入被长期拖延。

本指南帮您判断自己的产品适用哪条路线，以及如何走通。需要先说明的是：三条路线并非互斥，成熟品牌往往按产品线和市场阶段组合使用，先弄清楚每条路线的边界，再决定自己的组合。

## 了解中国监管类别

选路线之前，先弄清中国法规如何给您的产品定性。

### 一般食品（普通食品）

以营养补充为主要目的的产品，蛋白粉、维生素软糖、能量棒、花草茶、功能饮料等，可能被归为**普通食品**。普通食品走 GACC 注册和中国国家标准（GB 标准），**不能**在包装或营销中使用明确的功能宣称。

### 保健食品/蓝帽产品（保健食品）

作出特定功能宣称（如"增强免疫力""助消化""改善骨骼健康"）的产品，必须取得 **NMPA 保健食品注册**，俗称**"蓝帽子"**认证。这是更严格的过程，涉及安全性和功效评价。

### 跨境电商商品

通过跨境电商平台（天猫国际、京东全球购、抖音全球购）销售的产品，走另一套监管框架。只要通过合规的 CBEC 渠道直接卖给消费者，**不受境内食品法规约束**，但产品必须列入 CBEC 正面清单。

核心问题是：**您的产品里到底有什么成分，您想作出哪些宣称？** 答案决定路线。

## 途径一：GACC 一般食品进口

这是**不作明确功能宣称**的保健食品和功能食品最常见的路线。

### 它涵盖什么

根据**第 248 号令**，所有向中国出口食品的海外生产企业都必须完成 GACC（海关总署）注册。适用于：

- 蛋白粉（乳清、植物蛋白、胶原蛋白）
- 维生素和矿物质补充剂（定位为一般营养品时）
- 花草茶和植物冲饮
- 能量棒和代餐食品
- 功能饮料
- 运动营养品

### 要求

- 海外生产企业在 GACC 完成注册（在线申请，通常 5–10 个工作日内处理）
- 符合相应 GB 标准（营养标签 GB 28050、食品标签 GB 7718）
- 在 CNAS 认可的实验室完成检测，证明合规
- 每个零售单元加贴中文标签（预印或贴标）
- 中国境内有备案进口商

补充一点：走这条路线时，产品包装和详情页上的所有表述都要过一遍 GB 7718 和 GB 28050 的措辞红线。海外市场上常见的"护肝""助眠""增强免疫"等说法，在一般食品上都是禁止的，哪怕只是营销文案，也可能被职业打假人和市场监管部门盯上。

### 时间轴

| 阶段 | 时长 |
|------|------|
| GACC 生产企业注册 | 1–3 周 |
| 按 GB 标准检测 | 2–4 周 |
| 标签设计与翻译 | 1–2 周 |
| 首批发货 + 清关 | 1–2 周 |
| **合计** | **2–4 个月** |

### 成本

GACC 注册本身费用不高，主要成本在检测和标签合规，通常为 **2,000–8,000 美元**，视 SKU 数量和检测要求而定。

### 何时选择这条路线

✅ 产品是成分直接的营养补充剂

✅ 不需要作明确功能宣称

✅ 能为产品加贴中文标签

✅ 走批量进口（B2B 给分销商/零售商）

✅ 想要最大的零售渠道覆盖（线下 + 国内线上平台）

## 途径 2：NMPA 蓝帽保健食品注册

作**特定功能宣称**的产品，必须走 NMPA 蓝帽认证。

### 它涵盖什么

作出以下宣称的产品需要蓝帽注册：

- 增强免疫力
- 辅助降血脂
- 辅助降血糖
- 改善骨骼健康
- 促进消化
- 改善睡眠
- 抗氧化
- 体重管理
- 以及 NMPA 公布的其他保健功能

### 两条子路线

**1. 保健食品注册**

适用于风险较高、或使用 NMPA 批准目录以外新原料的产品。要求：

- 完整的安全性评价（毒理、稳定性）
- 功效/人体试食试验
- 生产现场核查
- NMPA 审批周期 12–24 个月
- 预估费用：30,000–80,000 美元以上

**2. 保健食品备案**

仅使用 NMPA 批准的保健食品原料目录内成分的产品，可走更简单的备案：

- 仅限多种维生素、矿物质和部分常见补充剂
- 无需人体试食试验
- 办理周期 3–6 个月
- 预估费用：5,000–15,000 美元

### 时间轴

| 阶段 | 注册 | 备案 |
|------|------|------|
| 预评估与文件 | 2–4 个月 | 1–2 个月 |
| 安全与功效检测 | 4–8 个月 | 1–2 个月 |
| NMPA 审评 | 12–18 个月 | 2–4 个月 |
| 发证 | 1 个月 | 1 个月 |
| **合计** | **18–30 个月** | **6–10 个月** |

### 何时选择这条路线

✅ 产品要作明确功能宣称

✅ 愿意投入可观的时间和预算

✅ 想通过**所有渠道**销售（含线下零售）

✅ 在中国做长期品牌布局

✅ 产品使用常见、成熟的原料

⚠️ **提醒：** 很多国际补充剂品牌先用途径一或途径三快速进入市场，之后再补途径二实现全渠道准入。蓝帽注册周期长、投入大，但一旦拿到证书，就意味着您可以在药店、商超、天猫京东国内店等所有渠道销售，并合法使用功能宣称，这是长期品牌资产，值得认真规划启动时机。

## 路线三：跨境电商（跨境电商）

跨境电商（CBEC）允许海外品牌通过获批平台直接向中国消费者销售，无需完成境内全套合规。

### 它涵盖什么

CBEC 适合满足以下条件的补充剂：

- 已列入 CBEC 正面清单（涵盖大多数常见补充剂、维生素和保健产品）
- 直接面向消费者销售（B2C，非批量进口）
- 从海外仓直接发货给消费者
- 不需要预印中文标签（按线上要求执行）

### 要求

- 平台开店（天猫国际、京东全球购等）
- 产品上架经平台审核
- 符合 CBEC 监管框架（第 486 号公告）
- 中文产品页、说明和警示语
- 无需境内预印中文标签
- 无需 GACC 生产企业注册
- 无需 NMPA 蓝帽认证

⚠️ **重要限制：** CBEC 正面清单会定期调整，部分新原料或高风险产品可能被移出。投入前务必核实产品品类在当前清单上。

### 时间轴

| 阶段 | 时长 |
|------|------|
| 平台店铺搭建 | 2–4 周 |
| 产品上架准备 | 2–4 周 |
| 首单成交 | 1–2 周 |
| **合计** | **1–3 个月** |

### 成本

CBEC 是成本最低的入场方式：

- 平台保证金和年费：5,000–20,000 美元（视平台而定）
- 物流搭建：2,000–5,000 美元
- 无境内认证费用

### 何时选择这条路线

✅ 想要最快、最省的市场进入

✅ 产品在 CBEC 正面清单上

✅ 接受纯线上分销

✅ 想先测试中国市场再投入境内渠道

✅ 品牌认知度高，消费者会主动搜索

⚠️ **限制：**

- 单笔订单限值：个人自用数量受限（一般每单 2,600 元，部分品类最高 5,000 元）
- 年度限值：每位消费者每年 26,000 元
- 不能走线下零售和国内电商平台分销（天猫 ≠ 天猫国际）
- 营销中不能作明确功能宣称（与普通食品相同）

还需要提醒的是：CBEC 渠道的订单和库存管理依赖海外仓和三单对碰系统，消费者下单后直邮或从保税仓发出，退换货流程与国内电商差异较大。把这些运营细节想清楚再上线，能避免很多售后纠纷。

## 决策框架：您的产品适合哪种路线？

按以下决策树判断：

**第 1 步：产品是保健食品或功能性食品吗？**

否 → 按一般食品处理（评估 GB 标准）
是 → 进入第 2 步

**第 2 步：产品要作特定功能宣称吗（免疫、睡眠、血糖等）？**

是 → **NMPA 蓝帽**路线（注册或备案）
否 → 进入第 3 步

**第 3 步：产品在 CBEC 正面清单上吗？**

是 → 考虑 **CBEC**（跨境电商）或 **GACC**（一般贸易）
否 → 进入第 4 步

**第 4 步：产品是否符合 GB 标准下的一般食品定义？**

是 → **GACC 路线**（注册后一般贸易进口）
否 → 咨询专业人士，产品可能需特殊审批

### 快速参考表

| 因素 | GACC 一般食品 | NMPA 蓝帽 | CBEC |
|------|--------------|-----------|------|
| 周期 | 2–4 个月 | 6–30 个月 | 1–3 个月 |
| 成本 | 2,000–8,000 美元 | 5,000–80,000 美元以上 | 5,000–25,000 美元 |
| 允许功能宣称 | 否 | 是 | 否 |
| 需要中文标签 | 是 | 是 | 否（仅线上） |
| 线下零售 | 是 | 是 | 否 |
| 国内电商 | 是（天猫/京东） | 是（天猫/京东） | 否（仅天猫国际/京东全球购） |
| 海关风险 | 低（合规时） | 低 | 低 |
| 品牌投入 | 中等 | 高 | 低（测试市场） |

选择时建议用三个问题做最终确认：产品能不能不说功能词？能不能接受 6 个月以上的等待期？需不需要线下渠道？三个答案都是"否"，就继续留在 CBEC 或 GACC；有一个答案是"是"，就要认真评估蓝帽路线。

## 补充剂品牌的战略建议

### 从 CBEC 或 GACC 起步，再升级 NMPA

最成功的国际补充剂品牌普遍采取分阶段策略：

- **第 1 年：** 通过 CBEC 验证需求、建立品牌认知
- **第 2 年：** 用 GACC 路线扩大分销
- **第 3 年起：** 申请 NMPA 蓝帽，实现全渠道准入

分阶段打法把前期风险降到最低，同时稳步逼近最大的市场空间。

### 标签合规对 GACC 路线至关重要

中国食品标签要求（GB 7718、GB 28050）与西方标准差异很大，常见问题包括：

- 营养声称格式错误（能量必须标 kJ，不能只标 kcal）
- 特定成分的强制警示语缺失
- 成分名称必须用批准的中文译名（不能直译）
- 过敏原声明须符合中国标准

印标签之前，务必先找标签合规专家审核一遍。

### 看懂蓝帽原料目录

走 NMPA 备案路线时，**保健食品原料目录**决定产品适用简单备案还是完整注册。常见已批准原料包括：

- 维生素 A、C、D、E、B 族
- 钙、镁、铁、锌
- 辅酶 Q10
- 褪黑素
- Omega-3 / 鱼油
- 益生菌（仅限特定菌株）

产品含有新原料或专有成分的，基本都要走完整注册。

### 规划前先核实 CBEC 正面清单

CBEC 正面清单（跨境电商零售进口商品清单）定期更新。截至 2026 年，多数常见补充剂都在清单上，但部分特殊成分可能不在。投入前先查最新版本。

### 考虑双路线策略

一些品牌同时运营 CBEC 和 GACC 两条路线：

- CBEC 承载旗舰产品（快速、直达消费者）
- GACC 承接面向国内分销商的批量出货
- 双线并行，最大化可覆盖市场

Sanitära karantäncertifikat för fartyg och luftfartyg byter utseende: vid in- och utresa, notera de nya namnen. Meddelande nr 29 år 2026 från Allmänna tullförvaltningen slår samman 10 gamla certifikat till 4 och delar upp fartygets befrielse- och kontrollcertifikat i 2 fristående certifikat.

Du kan själv ladda ner den elektroniska versionen via Single Window för internationell handel eller den offentliga tjänsteplattformen för tullen (online.customs.gov.cn). Papperscertifikat och elektroniska certifikat har samma juridiska giltighet. De direkta förbindelserna mellan de båda sidorna om Taiwansundet har dessutom två särskilda certifikat, ett för ankomst och ett för avresa från hamn.

Detta meddelande träder i kraft den 1 april 2026, och 11 ursprungliga certifikat upphävs samtidigt. Gamla sanitära fartygsbevis som utfärdats före ikraftträdandet och fortfarande är giltiga förblir dock giltiga, så du behöver inte skynda dig att förnya dem.

<!-- original -->

För att genomföra besluten och uppdragen från partiets centralkommitté och statsrådet, ytterligare förbättra företagsklimatet vid gränsövergångarna och höja nivån på förenklingen av gränsöverskridande handel, beslutar Allmänna tullförvaltningen att optimera och justera 11 sanitära karantäncertifikat för inresa och utresa av transportmedel, däribland det sanitära karantäncertifikatet för fartyg vid inresa. Härigenom meddelas följande.

Ett. De 10 certifikaten “Sanitärt karantäncertifikat för fartyg vid inresa”, “Karantäncertifikat för fartyg vid inresa”, “Sanitärt karantäncertifikat för transportmedel vid utresa”, “Karantäncertifikat för transportmedel”, “Sanitärt karantäncertifikat för fartyg vid avresa från hamn”, “Karantäncertifikat för fartyg vid ankomst till hamn”, “Sanitärt karantäncertifikat för fartyg vid ankomst till hamn”, “Sanitärt karantäncertifikat för luftfartyg vid avresa”, “Karantäncertifikat för luftfartyg vid ankomst”, “Sanitärt karantäncertifikat för luftfartyg vid ankomst” slås samman till de 4 certifikaten “Sanitärt karantäncertifikat för transportmedel vid inresa”, “Sanitärt karantäncertifikat för transportmedel vid utresa”, “Sanitärt karantäncertifikat för transportmedel vid ankomst till hamn på de direkta förbindelserna mellan de båda sidorna om Taiwansundet”, “Sanitärt karantäncertifikat för transportmedel vid avresa från hamn på de direkta förbindelserna mellan de båda sidorna om Taiwansundet” (nedan kallade sanitära karantäncertifikat för transportmedel vid inresa och utresa, mallar i bilagorna 1 till och med 4); “Befrielsecertifikat från hälsokontrollåtgärder för fartyg / Certifikat om hälsokontrollåtgärder för fartyg” justeras till de 2 certifikaten “Befrielsecertifikat från hälsokontrollåtgärder för fartyg”, “Certifikat om hälsokontrollåtgärder för fartyg” (nedan kallade fartygets hälsocertifikat, mallar i bilagorna 5 och 6).

Två. Operatörer eller ombud för fartyg och luftfartyg kan själva ladda ner den elektroniska versionen av de sanitära karantäncertifikaten för transportmedel vid inresa och utresa via Single Window för internationell handel eller den offentliga tjänsteplattformen för tullen (online.customs.gov.cn); via dessa kanaler kan de även ansöka om fartygets hälsocertifikat och själva ladda ner den elektroniska versionen.

Tre. Papperscertifikaten och de elektroniska certifikaten för de sanitära karantäncertifikaten för transportmedel vid inresa och utresa och för fartygets hälsocertifikat har samma juridiska giltighet.

Detta meddelande träder i kraft den 1 april 2026. Följande 11 certifikat upphävs samtidigt: “Sanitärt karantäncertifikat för fartyg vid inresa”, “Karantäncertifikat för fartyg vid inresa”, “Sanitärt karantäncertifikat för transportmedel vid utresa”, “Karantäncertifikat för transportmedel”, “Sanitärt karantäncertifikat för fartyg vid avresa från hamn”, “Karantäncertifikat för fartyg vid ankomst till hamn”, “Sanitärt karantäncertifikat för fartyg vid ankomst till hamn”, “Sanitärt karantäncertifikat för luftfartyg vid avresa”, “Karantäncertifikat för luftfartyg vid ankomst”, “Sanitärt karantäncertifikat för luftfartyg vid ankomst”, “Befrielsecertifikat från hälsokontrollåtgärder för fartyg / Certifikat om hälsokontrollåtgärder för fartyg”. Äldre “Befrielsecertifikat från hälsokontrollåtgärder för fartyg / Certifikat om hälsokontrollåtgärder för fartyg” som utfärdats före detta meddelandes ikraftträdande och fortfarande är giltiga förblir giltiga.

Härmed meddelas detta.

Bilagor: (1) Sanitärt karantäncertifikat för transportmedel vid inresa

(2) Sanitärt karantäncertifikat för transportmedel vid utresa

(3) Sanitärt karantäncertifikat för transportmedel vid ankomst till hamn på de direkta förbindelserna mellan de båda sidorna om Taiwansundet

(4) Sanitärt karantäncertifikat för transportmedel vid avresa från hamn på de direkta förbindelserna mellan de båda sidorna om Taiwansundet

(5) Befrielsecertifikat från hälsokontrollåtgärder för fartyg

(6) Certifikat om hälsokontrollåtgärder för fartyg

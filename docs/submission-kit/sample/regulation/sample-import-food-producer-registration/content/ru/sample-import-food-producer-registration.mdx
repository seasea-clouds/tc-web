Этот пример показывает структуру подачи нормативного акта.

## На кого распространяется

Зарубежные компании, производящие пищевую продукцию для экспорта в Китай.

## Что делать дальше

Подтвердить регистрационный статус каждого объекта до отправки партии.

<!-- original -->

**Статья 1**　Настоящие Положения распространяются на зарубежные компании, производящие пищевую продукцию для экспорта в Китай.

**Статья 2**　Зарубежная компания обязана зарегистрироваться в компетентном органе до экспорта.

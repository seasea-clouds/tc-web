## 每个产品都有合规路径

中国的进口法规并非"一刀切"。一柜法国葡萄酒面临的要求，和德国电子产品或韩国化妆品完全不同。弄清哪些法规适用于您的具体产品，是任何中国市场进入策略的第一步，也是最关键的一步，这一步做错了，后面所有的投入都可能白费。

本指南帮您按产品类别识别对应的合规要求，让您在启动进口前就清楚自己到底要办哪些手续。

## 食品和饮料产品

### 适用范围

如果您向中国出口食品、饮料、农产品或膳食补充剂，有两项主要要求必须满足：

**海关总署（GACC）注册（第 248 号令）** — 所有海外食品生产、加工和储存企业，都必须在中国海关总署完成注册。这项要求对进入中国的所有食品强制适用，从原材料到成品包装无一例外。未注册企业的货物，海关一律不予受理。

**中文标签合规（GB 7718）** — 所有进口食品必须加贴符合 GB 7718 标准的中文标签。标签必须包含产品名称、配料表、净含量、经销商信息、原产国、生产日期和保质期等要素。标签不合规是食品进口被拒收的头号原因。

### 类别一览

| 产品类型 | 主要要求 | 次要要求 |
|----------|----------|----------|
| 包装食品 | GACC 注册 | 中文标签（GB 7718） |
| 饮料（酒、咖啡、茶） | GACC 注册 | 中文标签（GB 7718） |
| 乳制品 | GACC 注册（18 类） | 中文标签 + 卫生证书 |
| 保健食品 | GACC 注册 + 审核 | 中文标签（特殊规则） |
| 原料类 | GACC 注册 | 中文标签（GB 7718） |
| 宠物食品 | GACC 注册 | 标签合规 + MOA（农业农村部）注册 |

## 电子、电器和工业产品

### 适用范围

**CCC 认证** — 中国强制认证（CCC）对电器、IT 设备、汽车零部件、照明和玩具等 17 个产品类别强制执行。目录内的产品没有有效的 CCC 证书，不得在中国进口、销售或使用。

CCC 目录之外的产品，仍可能根据具体行业标准需要办理自愿性认证或型式检测。比如部分工业机械、零部件，虽然不在强制目录里，但买家或下游渠道往往会要求提供检测报告。

### 类别一览

| 产品类型 | 主要要求 | 备注 |
|----------|----------|------|
| 家用电器 | CCC 认证 | 17 个强制类别之一 |
| IT 设备 | CCC 认证 | 大多数类别需要 CCC |
| 汽车零部件 | CCC 认证 | 安全相关部件 |
| 照明产品 | CCC 认证 | 强制类别 |
| 玩具及儿童用品 | CCC 认证 | 特定玩具类别 |
| 工业机械 | 自愿认证 | 可能适用型式检测 |
| 零部件 | 视最终用途而定 | 建议咨询专业人士 |

## 化妆品和个人护理

### 适用范围

**NMPA 化妆品备案或注册** — 国家药品监督管理局（NMPA）监管所有进入中国的化妆品。具体走备案还是注册，取决于产品被归为"普通化妆品"还是"特殊化妆品"。

**普通化妆品：** 洗发水、洁面产品、彩妆、香水等，进口前需向 NMPA 办理备案（通知备案）。流程包括产品检测、安全评估和通过 NMPA 在线系统提交资料。

**特殊化妆品：** 涉及防晒、染发、祛斑、防脱发等功效宣称的产品，需要在 NMPA 办理注册，这是更复杂的过程，涉及功效评价和更长的审查周期。

### 类别一览

| 产品类型 | 分类 | 主要要求 |
|----------|------|----------|
| 护肤品（保湿霜、精华） | 普通 | NMPA 备案 |
| 彩妆（粉底、口红） | 普通 | NMPA 备案 |
| 防晒产品 | 特殊 | NMPA 注册 |
| 染发产品 | 特殊 | NMPA 注册 |
| 沐浴露、洗发水 | 普通 | NMPA 备案 |
| 香水 | 普通 | NMPA 备案 |
| 防脱发产品 | 特殊 | NMPA 注册 |

## 跨境电商产品

### 适用范围

**跨境电商（CBEC）合规** — 通过天猫国际、京东全球购、抖音全球购、考拉等跨境电商渠道销售的产品，走的是与传统进口不同的监管路径。CBEC 允许海外品牌直接向中国消费者销售，无需设立中国实体办理进口清关。

但"不用清关"不等于"不用合规"。通过 CBEC 渠道销售的产品仍然必须满足：

- **正面清单合规：** 只有列入跨境电商零售进口商品清单（正面清单）的产品才能走此渠道
- **个人自用申报：** 每笔交易按个人自用处理，而非商业进口
- **标签要求：** 部分情形下接受电子标签
- **品牌授权：** 需要提供品牌所有权或授权证明

### 类别一览

| 产品类型 | 跨境电商资格 | 备注 |
|----------|--------------|------|
| 化妆品 | 是 | 仍需 NMPA 备案 |
| 食品补充剂 | 是 | 仍需 GACC 注册 |
| 婴幼儿配方奶粉 | 是 | 注册要求严格 |
| 电子产品 | 是 | 仍需 CCC 认证 |
| 时装及配饰 | 是 | 合规负担总体较低 |
| 家居用品 | 是 | 视产品而定 |

## 品牌保护：普遍要求

### 适用范围

**中国商标注册** — 中国实行商标先申请制度：谁先在中国注册商标，谁就拥有商标权，与谁先在全球使用该商标无关。如果您的品牌未在中国注册，您可能失去使用自己品牌名称的权利，别人可以先注册，然后反过来向您主张权利。

商标注册对任何认真对待中国市场的公司来说都不是可选项。它能保护品牌免受假冒侵权，让您能在主流电商平台正常开店销售，并为您提供维权的法律基础。这项要求适用于**每一个产品类别**，食品、电子、化妆品、时尚、工业品，无一例外。

## 如何确定您的合规路径

按照以下步骤确定适用于您产品的法规：

**第 1 步：确定产品类别** — 判断您的产品属于食品、电子产品、化妆品、一般消费品还是工业设备。这决定了主要的监管框架。

**第 2 步：核查强制要求** — 确认产品是否落入任何强制合规计划（食品走 GACC、电子产品走 CCC、化妆品走 NMPA）。

**第 3 步：评估标签和包装要求** — 几乎所有进口产品都需要某种形式的中文标签，具体要求因类别而异。

**第 4 步：评估销售渠道** — 传统进口与跨境电商遵循不同规则，您的分销策略直接决定适用哪些要求。

**第 5 步：注册商标** — 无论产品类别如何，商标注册都应在合规流程之前或与合规流程并行完成。

## 常见的误解

### “我的产品已经在其他国家销售，所以中国的合规性应该是类似的。”

中国的监管体系是独特的。在欧盟、美国或日本获批的产品，并不会自动获得中国市场的准入资格。每一款产品都必须走一遍中国特有的合规流程，海外认证报告通常只能作为参考，不能替代中国国内的备案或注册。

### “跨境电商意味着我不需要合规。”

跨境电商确实降低了一些门槛，但没有消除合规要求。通过 CBEC 渠道销售的产品，GACC 注册、CCC 认证、NMPA 备案等产品特定法规依然适用。平台可以帮您完成清关，但监管责任最终仍落在品牌方身上。

### “我只需要一种类型的合规性。”

大多数产品需要多个合规步骤。食品既需要 GACC 注册也需要标签合规；电子产品可能需要 CCC 认证、标签合规和商标注册三件事同时做。合规很少是单一步骤就能完成的事。

### “所有国家/地区的合规流程都是相同的。”

不同国家的企业与中方监管机构打交道的方式不同。部分国家与中方签有互认协议（如部分乳制品产地的政府间推荐机制），另一些则必须直接向中国主管部门提交申请。即便同一个国家，不同产品类别的办理渠道也可能不同，流程因原产国和产品而异，切忌照搬其他市场的经验，也不要轻信网上流传的二手攻略。

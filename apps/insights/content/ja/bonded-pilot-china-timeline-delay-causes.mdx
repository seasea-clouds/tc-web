保税パイロットが開始から稼働までどれくらいかは、十四〜三十四週ほどの条件付きの幅に収まり、特定の日付に固定されない。どちらの端になるかはクリティカルパス上の二つ、実体登録とプラットフォーム・資金口座、そして六類の滑りのうちお客様が握る分で決まる。原資料第七章 Clear Numbers の読み方は、時間は幅、費用は構造、リターンはお客様のモデルに委ねるというもの。本稿は第七章四頁を一気に解説する。クリティカルパスと九段階の日程、当社側とお客様ご入力の幅表、六類の滑り因子と代償、六節目と必要入力。他章の予習は要らない。

![SinoTrade Compliance ブランド資料第七章の扉：章号 07、章名 Clear Numbers、章旨一行と三つの導きの問い](/images/insights/bonded-pilot-china-timeline-delay-causes/chapter-07-clear-numbers-divider.webp)

図はブランド資料第七章の扉から。章号 07、章名 Clear Numbers、直訳は「明快な数字」。扉の章旨一行は、時間は幅で示し、費用は構造で示し、リターンはお客様自身のモデルで算出する。扉は本章が答える三問も並べる。開始から稼働までクリティカルパスがどこで詰まるか、人・資金・材料がどれだけ要るか、注文あたり粗利を動かすパラメータはどれか。本稿はこのうち時間と日程を扱い、四頁を順に解説する。

## 開始から稼働までのクリティカルパスと九段階

日程図の核心記号は D-Day。稼働日、最初の保税放行日、第一段階で最も厳しい検査点でもある。時間軸は今日から第三十四週まで。凡例は三色。濃紺がクリティカルパス、中青が非クリティカル段階、淡青が D-Day 後の定常運用。九行を上から順に。S0 診断検査は約二週、図上は中値で演示。S1 実体登録は四〜十二週、クリティカルパス。S2 プラットフォームと資金口座は四〜八週、S1 と並行。S3 製品参入と届出は二〜六週、S2 と並行。S4 初程物流と入区は二〜四週。S5 三書類通関は一〜二週。続く D-Day 初回放行が鍵の検査点。S6 精算は月次。S7 以降は定常運用。

![第七章の日程図：Kick-off to Launch、クリティカルパスと九段階のガント図、S0–S7+ 九本の時間バーと D-Day 検査点の縦線](/images/insights/bonded-pilot-china-timeline-delay-causes/kick-off-to-launch-critical-path-nine-phases.webp)

頁の題は Kick-off to Launch: Critical Path and Nine Phases、開始から稼働までのクリティカルパスと九段階。九段階は九本のリレーではない。S1 は S2 と並行、S3 も S2 と並行で、一本の線になるのはクリティカルパス上の区間だけ。本稿は続く三頁の日程の幅、滑り因子、節目まで合わせて解説し、本章他モジュールの予習は要らない。

クリティカルパスが S1 と S2 を通る理由は図下のカードが示す。実体と資金口座が、出店できるか、通関できるか、精算できるかを決める。二つが固まるまで下流はすべて待ち、二つを同時に動かして初めて経路全体が錨を下ろす。

D-Day の前後は二つの帳簿。前は一度きりの構築、実体・届出・入区・初便に予算と人員を一度投下。後は定常運用、精算・顧客対応・再購入・台帳を月次で回す。二段の予算は分け、一枚の表に混ぜない。

## 日程の幅：当社が握る分とお客様ご入力

稼働まで十四〜三十四週ほど、条件付きの幅。並行日程が省くのは確かな時間。S1 と S2 の並行で四〜六週、S3 と S2 の並行でさらに二〜四週。図の六本の参考期間は段階ごとに示し、両端とも実形で中値は取らない。

## 最速十四週に何が要るか、通しの演算

原頁は最速十四週を四条件に分ける。一、実体はプラットフォーム代理経路、当社サービスの一つで S1 を四週内に抑える。二、CoA と試験報告書が揃い、S3 は再試験を起こさない。三、S2 の店舗と資金口座を即座に並行開始。四、港の希望と貨量を早く確定、文書の分割到着は日程を長端へ押す。四つともお客様の手にあり、当社はその条件でその場でモデルを実演できる。

演示条件で十四週を通す。S0 は二週で開始。S1 は代理経路で四週に着地。S2 は八週の上限を並行で消化し、クリティカルパスに時間を足さない。S3 は六週を S2 と並行で吸収。S4 は二〜四週のうち二週で読む、貨量の早期確定と初程の窓逃し回避が前提。S5 は一〜二週のうち一週で読む。クリティカルパスは二週＋四週＋四週＋二週、約十二〜十四週で幅の下端。逆に実体が WFOE 登録なら S1 は十二週の上限に張り付き、文書の分割到着で段階は直列待ち、港の希望が遅れれば二つの代替案が要り、貨量が遅れれば初程物流は窓を逃す。重なれば日程は三十四週の長端へ滑る。両端を出して初めて見通しが立つ。

口径を明かす。幅は条件付き。三十四週の上限は WFOE 登録と文書分割到着の組合せに対応。演示で中値を取る S0 を除き、図の期間はすべて幅で中値は取らない。

## 六類の滑りとその代償

六類の滑りが幅のどちらの端かを決め、バーの長さは相対影響、条件付きの口径。帰属は責任の三分けに従う。濃紺が当社、中青がお客様ご提供、墨色が当社との並行。

| 帰属 | 因子 | 代償 |
| --- | --- | --- |
| お客様ご提供 | CoA と試験準備 | 再試験：S3 が二〜六週滑る |
| お客様ご提供 | 文書の回転 | リスト遅着：S0 起点が約二週滑る |
| お客様ご提供 | SKU と分類の負荷 | 品目が多いほど届出が長引く |
| 当社 | 根拠照合 | 手戻り：段階内で吸収 |
| 並行 | 初程モード | モード選択が S4 に影響 |
| お客様ご提供 | 実体経路（四〜十二週） | 確定遅れ：経路は比例して順延 |

| 遅延ケース | 順延の代償 | 影響 |
| --- | --- | --- |
| SKU リストが二週遅れ | 約二週滑る | S0 起点が順延 |
| CoA 欠落で再試験 | 二〜六週滑る | S3 が順延 |
| 実体経路の決定遅れ | 比例して順延 | クリティカルパス |
| 港での処理 | 標準処理時間 | S5 日程の上限 |
| 貨量の遅れ | 固定週数なし | S4 に影響 |

前三因子はお客様の手に。CoA 準備、文書の回転、SKU と分類の負荷、この三つが幅のどちらの端かを決める。当社が実行するのは再試験計画、文書リスト、リスト照合と補完。原本と授権書類はお客様がご提供。

## 六節目とお客様の入力

M1–M6 は双方で確認する成果の節目、支払リズムに連動。節目は段階に錨を下ろす。S3 製品参入と届出は S2 と並行で独立節目は置かない。六節目を順に挙げる。

- M1、S0 完了：参入会議と階層承認、入力は SKU リストと CoA。
- M2、S1 完了：実体と税関登録の完了、入力は実体経路の決定。
- M3、S2 完了：店舗と口座の開設、テスト注文の実行、入力は表示戦略。
- M4、S4 完了：入区と台帳の届出、入力は在庫量。
- M5、S5 完了：D-Day 初回放行、入力は港の希望。
- M6、S6 完了：初回精算と照合の完了、支払は成果物ごと。

| 入力 | 用途 | 欠落時の影響 |
| --- | --- | --- |
| 仕様付き SKU リスト | 分類・届出 | S0 起点が順延 |
| 同ロット CoA | 参入会議 | S3 が順延 |
| 試験報告書 | 補完の裏付け | 固定週数なし |
| 在庫計画 | 初程の日程 | S4 日程が順延 |
| 実体経路の決定 | S1 開始 | クリティカルパスが順延 |
| 港の希望 | 目標港の確定 | 固定週数なし |
| 表示戦略 | 内容審査 | 固定週数なし |

入力の最遅は三つ覚える。SKU リストと CoA は S0 開始前、在庫量は S4 日程前、実体経路は S1 開始前。六節目は月次レビューの共通基線。各節目に項目ごと検収できる成果物が一つ対応し、共同確認後に節目は支払リズムへ入り、節目の状態は月次台帳で更新され、日程曲線と同一ソース。

最後に口径。十四〜三十四週は条件付きの参考幅で確約ではない。演示で中値を取る S0 を除き、図の期間はすべて幅で中値は取らない。節目は双方確認の節点で、支払ごとに成果物が一つ対応する。WFOE 登録と文書の分割到着が幅を長端へ押す主因。ご自身の保税日程はこの順で。S0 開始前に SKU リストと同ロット CoA を揃え、第一週に実体経路を決め、S1 着地の当日に S2 を並行で走らせ、後は六節目で月次レビュー。中国市場向けパッケージに、この日程表と節目に対応する実行材料を用意した。製品リストと目標稼働日をお持ちください、[お問い合わせ](/ja/packages/)。

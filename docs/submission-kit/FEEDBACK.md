# 编写者建议（FEEDBACK.md）

工具包内**唯一允许编写者直接编辑**的文档。`README.md` 属框架层（SEALED），
只能由维护者修改并重签；判据走 `rules import`、词表走 `glossary`、稿件问题
按 `README.md` 的「问题回流」处理。除本文件外，编写者不需要、也不应改工具包
里的任何其他文件。

## 投稿时这样做

- **有可机检的缺陷** → 写包外 `tmp/rule-draft/` 草稿并 `submit.py rules import`，
  不要写在这里（本文件不是判据真源）。
- **缺词形/术语/机构名** → `submit.py glossary lexicon add` 等受控入口，
  不要写在这里。
- **对框架代码、文档、判据设计、工具体验的建议** → 写在本文件下方清单。

## 条目格式

每条一段，五要素齐全：

```
### YYYY-MM-DD · <提出人 ID> · <涉及文件或主题>
- 现状：<现在是什么行为/写法>
- 建议：<希望改成什么>
- 理由：<哪篇稿件或哪个场景暴露的问题，可给出规则号/语向/文号>
```

## 中国のサプリメント市場の複雑さ

中国は健康補助食品と機能性食品の世界第 2 位の市場で、市場規模は 850 億ドルを超え、毎年 8〜12% で成長しています。この需要は、人口の急速な高齢化、中間層の健康意識の高まり、パンデミック後のウェルネスへの関心の高まりによって支えられています。日本製の健康食品は品質への信頼が厚く、特にアミノ酸、コラーゲン、プロバイオティクスなどの分野で人気があります。

しかし、海外ブランドにとってこの市場への参入は簡単ではありません。規制の枠組みでは、製品は **3 つの異なる経路** に分かれており、それぞれ要件、スケジュール、コストが異なります。間違ったルートを選択すると、税関での差し押さえ、罰金、市場アクセスの遅延が発生し、数か月、場合によっては数年を失う可能性があります。

このガイドは、どのルートが自社製品に適用されるのか、そしてそれを成功裏に進める方法を理解するのに役立ちます。

## 中国の規制カテゴリーを理解する

ルートを選択する前に、中国の規制が自社製品をどのように分類しているかを理解する必要があります。

### 一般食品 (普通食品)

プロテインパウダー、ビタミングミ、エナジーバー、ハーブティー、機能性飲料など、栄養を主な目的とする製品は、中国法のもとで **一般食品** に該当する可能性があります。一般食品は GACC 登録と中国国家基準 (GB 基準) に準拠します。パッケージやマーケティングで明示的な健康効果を謳うことはできません。

### 健康食品 / ブルーハット製品 (保健食品)

特定の健康効果 (例:「免疫システムを強化する」「消化を助ける」「骨の健康を改善する」) を謳う製品には、**NMPA 健康食品登録**、一般に **「ブルーハット」(蓝帽子)** と呼ばれる認証が必要です。これは安全性と有効性の試験を含む、はるかに厳格なプロセスです。日本で機能性表示食品として販売している製品も、中国ではこの区分の検討が必要になります。

### 越境電子商取引商品

越境電子商取引プラットフォーム (Tmall Global、JD Worldwide、Douyin Global) を通じて販売される商品は、異なる規制枠組みに従います。承認された CBEC チャネルを通じて消費者に直接販売される限り、**国内の食品規制の対象にはなりません**。ただし、製品は CBEC ポジティブリストに掲載されている必要があります。

重要な質問は次のとおりです。**自社製品には実際に何が含まれており、どのような効果を謳いたいのか。** この 2 点が、選択すべきルートを大きく左右します。同じ成分でも、効果を謳うかどうかで一般食品と健康食品の区分が分かれるため、商品戦略の段階から規制の観点を取り入れることが重要です。

## ルート 1: GACC 一般食品輸入

これは、**明示的な健康効果を謳わない** 健康補助食品や機能性食品に最も一般的なルートです。

### 対象となる内容

**政令第 248 号** に基づき、中国に輸出するすべての海外食品製造業者は GACC (中国税関総署) への登録が必要です。対象には以下が含まれます。

- プロテインパウダー (ホエイ、植物性、コラーゲン)
- ビタミン・ミネラルのサプリメント (一般栄養食品として位置付ける場合)
- ハーブティー・植物性煎じ薬
- エナジーバー・完全栄養食
- 機能性飲料
- スポーツ栄養製品

### 要件

- GACC への海外製造業者登録 (オンライン申請、通常 5〜10 営業日で処理)
- 関連する GB 規格への準拠 (栄養表示は GB 28050、一般食品表示は GB 7718)
- 適合性を実証するための CNAS 認定試験機関での試験
- すべての小売単位への中国語ラベル (印刷またはステッカー)
- 中国国内の輸入者 (輸入者記録)

### タイムライン

| フェーズ | 期間 |
|---------|------|
| GACC 製造業者登録 | 1〜3 週間 |
| GB 規格に基づく製品試験 | 2〜4 週間 |
| ラベルデザインと翻訳 | 1〜2 週間 |
| 初回出荷と通関 | 1〜2 週間 |
| **合計** | **2〜4 か月** |

### コスト

GACC 登録は比較的リーズナブルです。主なコストは製品試験とラベル適合で、通常 SKU 数と試験要件に応じて **2,000〜8,000 ドル** の範囲です。

### このルートを選ぶ場合

✅ 製品がシンプルな栄養補助食品である

✅ 明示的な健康効果を謳う必要がない

✅ 製品に中国語ラベルを貼付できる

✅ バルク出荷する (代理店・小売への B2B)

✅ 小売チャネルへの最大限のアクセスが必要 (オフライン + オンライン国内プラットフォーム)

## ルート 2: NMPA ブルーハット健康食品登録

**特定の健康効果** を謳う製品には、NMPA ブルーハット認証が必須の経路です。

### 対象となる内容

以下の効果を謳う製品にはブルーハット登録が必須です。

- 免疫システムのサポート
- 血中脂質の管理
- 血糖値の調整
- 骨の健康の改善
- 消化器の健康
- 睡眠の改善
- 抗酸化作用
- 体重管理
- NMPA が定めるその他の特定の健康機能

### 2 つのサブルート

**1. 健康食品登録 (注册)**

リスクの高い製品、または NMPA の承認リストにない新規成分を使用する製品が対象です。必要なもの:

- 完全な安全性評価 (毒性、安定性)
- 有効性・ヒト試験
- 製造現場の検査
- NMPA による処理期間 12〜24 か月
- 推定費用: 30,000〜80,000 ドル以上

**2. 健康食品届出 (备案)**

NMPA が承認した健康食品原料リストに掲載された成分のみを使用する製品が対象です。これはより簡素な通知プロセスです。

- マルチビタミン、ミネラル、特定の一般的なサプリメントに限定
- ヒト試験は不要
- 処理期間 3〜6 か月
- 推定費用: 5,000〜15,000 ドル

### タイムライン

| フェーズ | 登録 | 届出 |
|---------|------|------|
| 事前評価と文書化 | 2〜4 か月 | 1〜2 か月 |
| 安全性・有効性試験 | 4〜8 か月 | 1〜2 か月 |
| NMPA 審査 | 12〜18 か月 | 2〜4 か月 |
| 証明書発行 | 1 か月 | 1 か月 |
| **合計** | **18〜30 か月** | **6〜10 か月** |

### このルートを選ぶ場合

✅ 製品が特定の健康効果を謳う

✅ 十分な時間と予算を投資する意思がある

✅ すべてのチャネル (オフライン小売を含む) で販売したい

✅ 中国での長期的なブランド構築を目指す

✅ 製品が一般的で実績のある成分を使用している

⚠️ **注意:** 多くの国際サプリメントブランドは、迅速に市場参入するためにルート 1 またはルート 3 から始め、完全な市場アクセスを得るために後からルート 2 に進みます。

## ルート 3: 越境電子商取引 (越境EC)

越境電子商取引 (CBEC) により、外国ブランドは国内での完全なコンプライアンスを経ずに、承認されたプラットフォームを通じて中国の消費者へ直接販売できます。

### 対象となる内容

CBEC は以下のサプリメントに最適です。

- CBEC ポジティブリストに掲載されている (一般的なサプリメント、ビタミン、健康製品のほとんどが含まれる)
- 消費者に直接販売される (B2C、バルク輸入ではない)
- 海外倉庫から消費者へ直接発送される
- 中国語の事前印刷ラベルが不要 (オンライン限定の要件のみ適用)

### 要件

- プラットフォーム登録 (Tmall Global、JD Worldwide など)
- プラットフォームによる商品リスト承認
- CBEC 規制枠組みへの準拠 (486 号公告)
- 中国語の製品ページ、説明書、注意書き
- 国内の事前印刷中国語ラベルは不要
- GACC 製造業者登録は不要
- NMPA ブルーハット認証は不要

⚠️ **重要な制限:** CBEC ポジティブリストは定期的に更新されます。一部の新規成分やリスクの高い製品は除外される場合があります。自社製品のカテゴリーが最新リストに含まれているかを必ず確認してください。

### タイムライン

| フェーズ | 期間 |
|---------|------|
| プラットフォームストア開設 | 2〜4 週間 |
| 商品リスト準備 | 2〜4 週間 |
| 初回販売 | 1〜2 週間 |
| **合計** | **1〜3 か月** |

### コスト

CBEC 市場参入は最も費用対効果の高いルートです。

- プラットフォーム保証金と年会費: 5,000〜20,000 ドル (プラットフォームにより異なる)
- 物流構築: 2,000〜5,000 ドル
- 国内認証費用は不要

### このルートを選ぶ場合

✅ 最速かつ最も費用対効果の高い市場参入を望む

✅ 製品が CBEC ポジティブリストに掲載されている

✅ オンライン限定の販売で問題ない

✅ 国内チャネルにコミットする前に中国市場をテストしたい

✅ 製品のブランド認知度が高く、消費者が積極的に探してくれる

⚠️ **制限事項:**

- 単一注文の上限: 個人使用の数量制限が適用 (通常 1 注文あたり 2,600 元、一部カテゴリーは最大 5,000 元)
- 年間上限: 消費者 1 人あたり年間 26,000 元
- オフライン小売や国内 EC プラットフォームでの販売は不可 (Tmall と Tmall Global は別)
- マーケティングでの明示的な健康効果の謳い文句は不可 (一般食品と同じ制限)

## 意思決定の枠組み: どのルートを選ぶか

このデシジョンツリーを使って、最適なルートを特定します。

**ステップ 1: 自社製品は健康補助食品または機能性食品ですか?**

- いいえ → 一般食品として扱い (GB 基準の評価へ進む)
- はい → ステップ 2 へ

**ステップ 2: 製品は特定の健康効果 (免疫力、睡眠、血糖値など) を謳いますか?**

- はい → **NMPA ブルーハット** ルート (健康食品の登録・届出が必要)
- いいえ → ステップ 3 へ

**ステップ 3: 製品は CBEC ポジティブリストに掲載されていますか?**

- はい → **CBEC** (越境 EC) または **GACC** (一般貿易) ルートを検討
- いいえ → ステップ 4 へ

**ステップ 4: GB 基準の一般食品に該当しますか?**

- はい → **GACC ルート** (GACC 登録による一般貿易輸入)
- いいえ → 専門家に相談 (特別な審査が必要な可能性)

### 早見表

| 要素 | GACC 一般食品 | NMPA ブルーハット | CBEC |
|------|-------------|------------------|------|
| 期間 | 2〜4 か月 | 6〜30 か月 | 1〜3 か月 |
| コスト | 2,000〜8,000 ドル | 5,000〜80,000 ドル以上 | 5,000〜25,000 ドル |
| 健康効果の表示 | 不可 | 可 | 不可 |
| 中国語ラベル | 必要 | 必要 | 不要 (オンラインのみ) |
| オフライン小売 | 可 | 可 | 不可 |
| 国内 EC | 可 (Tmall/JD) | 可 (Tmall/JD) | 不可 (Tmall Global/JD Worldwide のみ) |
| 通関リスク | 低 (適合時) | 低 | 低 |
| ブランドコミットメント | 中 | 高 | 低 (市場テスト) |

## サプリメントブランドの戦略的ヒント

### CBEC または GACC から始めて、NMPA へ段階的に進む

中国で最も成功している国際サプリメントブランドは、段階的なアプローチを取っています。

- **1 年目:** CBEC で参入し、需要を検証してブランド認知を構築
- **2 年目:** より広い流通のため GACC ルート製品を展開
- **3 年目以降:** 完全な市場アクセスのため NMPA ブルーハットを申請

この段階的アプローチにより、初期リスクを最小限に抑えながら、市場の可能性を最大限に引き出せます。日本ブランドはまず越境 EC で人気商品の反応を確認し、そのデータを基に一般食品輸入やブルーハット申請へ投資するパターンが一般的です。どの段階でも、規制変更の動向を追いながら柔軟に戦略を調整できる体制が重要です。

### ラベル適合は GACC ルートの鍵

中国の食品表示要件 (GB 7718、GB 28050) は日本の基準と大きく異なります。一般的な問題には次のようなものがあります。

- 栄養表示形式の誤り (エネルギーは kcal だけでなく kJ で表示する必要がある)
- 特定成分の必須警告の欠落
- 成分名は承認された中国語訳を使う必要がある (直訳は不可)
- アレルゲン表示は中国の基準に従う

ラベルを印刷する前に、ラベル適合の専門家と協力してください。

### ブルーハットの成分リストを理解する

NMPA 届出ルートの場合、**承認済み健康食品原料カタログ** (保健食品原料目录) によって、製品が簡素な届出プロセスに適合するか、完全な登録が必要かが決まります。一般的に承認されている成分には以下があります。

- ビタミン A、C、D、E、B 群
- カルシウム、マグネシウム、鉄、亜鉛
- コエンザイム Q10
- メラトニン
- オメガ 3 / 魚油
- プロバイオティクス (特定の菌株のみ)

製品に新規または独自の成分が含まれる場合は、完全な登録ルートが必要になると見込んでください。日本のサプリメントで一般的な成分でも、中国の承認カタログに未掲載の場合は登録審査の対象となり、期間とコストが大幅に増加します。

### 計画前に CBEC ポジティブリストの状況を確認する

CBEC ポジティブリスト (越境電子商取引小売輸入リスト) は定期的に更新されます。2026 年現在、一般的なサプリメントのほとんどは含まれていますが、一部の特殊成分は含まれていない場合があります。このルートにコミットする前に最新版を確認してください。

### デュアルルート戦略を検討する

一部のブランドは CBEC と GACC の両ルートを同時に運用しています。

- 主力製品は CBEC (迅速な消費者直販)
- 国内代理店への大量出荷は GACC
- 組み合わせにより総獲得可能市場を最大化

Гэты прыклад паказвае структуру падачы нарматыўнага акта.

## На каго пашыраецца

Замежныя кампаніі, якія выпускаюць харчовую прадукцыю для экспарту ў Кітай.

## Што рабіць далей

Пацвердзіце рэгістрацыйны статус кожнага аб'екта да адпраўкі партыі.

<!-- original -->

**Артыкул 1**　Гэтыя Палажэнні пашыраюцца на замежныя кампаніі, якія выпускаюць харчовую прадукцыю для экспарту ў Кітай.

**Артыкул 2**　Замежная кампанія павінна зарэгістравацца ў кампетэнтным органе да экспарту.
